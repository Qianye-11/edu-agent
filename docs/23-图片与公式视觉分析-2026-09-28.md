# 图片与公式视觉分析（2026-09-28）

## 1. 能力范围

本阶段把原来的“检测图片并提醒看原页”升级为可实际调用的视觉分析链路：

- 上传题目截图、公式图片、函数图象、几何图、表格或统计图；
- OCR 提取题干文字；
- 同时输出公式的 LaTeX 与纯文本形式；
- 根据用户附带的问题解释图象、关系和解题步骤；
- 对可安全解析的纯文本公式追加本地 SymPy 语法、数值等式或恒等式检查；
- 直接分析教材或上传 PDF 的指定页面。

支持 JPEG、PNG、GIF、WebP，默认单图上限 8 MB。用户文件只在内存中读取，不作为上传
原件落盘；教材页面仍复用 `data/page_cache/` 的原页缓存。

## 2. 调用链路

```text
图片上传 / 教材原页
        ↓ 内容签名、大小和权限检查
OpenAI 兼容视觉模型（默认 deepseek-flash）
        ↓ 结构化 JSON
OCR 文本 + 公式 + 图象/几何分析 + 置信度
        ↓
受限 SymPy 本地复核 → Markdown 回答 → 会话持久化
```

图片内出现的文字一律视为待分析数据，提示词明确禁止执行图片中的指令。视觉模型无法确认
的字符必须标记不确定，不允许凭教材常识补写。

## 3. 配置

视觉能力默认复用已有 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_BASE_URL`：

```dotenv
VISION_MODEL=deepseek-flash
VISION_MAX_BYTES=8388608
VISION_TIMEOUT=120
```

需要切换到其他 OpenAI 兼容视觉服务时，可额外设置：

```dotenv
VISION_API_KEY=...
VISION_BASE_URL=https://example.com/v1
VISION_MODEL=your-vision-model
```

`GET /api/vision/status` 只检查配置，不发起网络或计费请求。当前本机返回 `ready=true`。

## 4. API

### 4.1 上传图片

`POST /api/vision/analyze`，`multipart/form-data`：

| 字段 | 说明 |
|---|---|
| `file` | JPEG/PNG/GIF/WebP 图片 |
| `question` | 希望针对图片回答的问题，可空 |
| `session_id` | 当前会话，可空；为空时自动创建 |
| `confirm` | 权限确认后的重试标记 |

### 4.2 分析教材原页

`POST /api/vision/page`，JSON：

```json
{"page": 177, "source": "", "question": "解释图中的单位圆定义", "dpi": 220,
 "session_id": "", "confirm": true}
```

`source` 为空时只允许读取配置中的教材 PDF；非空时只能匹配已经登记的上传 PDF，不接受任意
服务器文件路径。

## 5. 前端入口

- 会话输入框的上传按钮现在同时接受 PDF 和图片；
- PDF 继续进入知识库，图片直接进入视觉分析；
- 若输入框已有问题，该问题会随图片一起提交；
- 回答引用卡带页码时，可以点击引用卡分析该教材原页；
- 首次发送图片到远程视觉模型时弹出权限确认，也可以在权限设置中改为始终允许或禁止。

## 6. 安全与准确性

- 依据文件内容签名判断格式，不信任文件扩展名和浏览器 MIME；
- 上传按块读取并限制大小；
- API Key 只放请求头，不写入结果、日志或会话；
- SymPy 复核只接受白名单字符、变量和函数，不直接执行模型生成代码；
- `numeric_true/identity_true` 仅代表识别后的文本公式通过本地检查，不证明图片 OCR 必然正确；
- 低清晰度、遮挡、手写体和复杂排版仍需人工核对原图。
