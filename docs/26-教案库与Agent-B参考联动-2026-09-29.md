# 教案库与 Agent B 参考联动

> 完成日期：2026-09-29  
> 范围：当前 5174 教案中心、教案库抽屉、DOCX 入库、Agent B 参考教案

## 1. 本阶段交付

当前版本已恢复并升级“教案库 · 模板中心”。它是教案画布右侧的全高抽屉，不再是简单的模板下拉框。老师可在一个界面完成：

- 保存当前多页教案；
- 导入学校 DOCX 到教案库；
- 按课题、学科、年级、课型或标签搜索；
- 按“我的教案 / 规范模板 / 学校模板”筛选；
- 预览并打开已有教案，或从只读规范模板新建副本；
- 选择最多 5 篇教案作为 Agent B 的参考材料；
- 将自有教案软删除到 `content/lesson_library/_trash/`，便于恢复。

## 2. 数据与接口

教案条目存放在 `content/lesson_library/*.json`，每条保留标题、学科、年级、课型、分类、标签、正文 HTML 与更新时间。当前接口为：

| 方法 | 接口 | 用途 |
|---|---|---|
| GET | `/api/lesson-library` | 返回教案摘要、缩略预览与分类 |
| GET | `/api/lesson-library/{id}` | 打开完整教案正文 |
| POST | `/api/lesson-library` | 新建或更新“我的教案 / 学校模板” |
| DELETE | `/api/lesson-library/{id}` | 软删除非内置条目 |

内置 3 套规范模板首次读取时自动建立，`locked=true`，前端不提供删除按钮，也不能覆盖原文件。

## 3. 多页兼容

画布入库时使用 `<div class="lesson-page-break"></div>` 连接页面。重新打开条目时，前端会按该标记拆回多个可编辑 A4 页面，因此“保存到库 → 关闭 → 再打开”不会把多页教案压成单页。

从规范模板打开时只创建可编辑副本，不绑定内置条目；从“我的教案”打开时会记录当前条目 ID，后续再次保存会更新同一条教案，避免每次都产生重复副本。新建、套模板或普通 DOCX 导入会解除此绑定。

## 4. Agent B 联动

卡片上的“给 Agent B 参考”会把条目 ID 保存到浏览器本地：

`localStorage: edu_lesson_library_refs_v1`

Agent B 请求新增 `reference_ids` 字段。后端读取所选教案，整理成参考上下文后再生成或修改当前教案；失效或已删除的 ID 会在下次加载教案库时自动清理。界面底部和 Agent B 面板都会显示当前参考教案数量。

Agent B 的入口采用教案画布内悬浮按钮：点击打开面板后入口自动隐藏，关闭面板右上角的“×”后恢复；按住拖动可以调整位置。只有移动超过 5px 才进入拖动状态，避免轻微手抖触发误操作。位置记录在 `localStorage: edu_lesson_agent_fab_pos_v1`，刷新后自动恢复，并在窗口缩放时重新约束到可见区域。

## 5. 安全与边界

- 入库正文上限为 2 MB；过大的内嵌图片会被后端拒绝。
- 前端展示与回填前会移除脚本、事件属性、iframe、表单与危险 URL 样式。
- 列表接口只返回轻量预览，完整正文只在打开单条时读取。
- 当前 DOCX 导入保留段落、表格和文字样式；图片仍以位置提示呈现，图片原样入库是后续阶段。
- 教案库是项目级本地知识库，当前未做账号级同步与多人权限控制。
