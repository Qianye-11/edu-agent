# 23 · 预览版式改造计划书（v1.16.0）

> **这份文档是什么**：把 `docs/22`（**规格**：数值 / 路线 / 闸门定义）变成"**谁做什么、做完怎么验**"的排期。
> **三者关系**：`docs/22` = 规格（唯一数值源与验收定义）；本文 = 排期与任务分解；`docs/19` = 已交付功能 + 后续章节 §8–§12（编辑器 / 模板 / 填充器）。
> 用法：看 §0 知道要做哪几件事；看 §3 知道每个任务改哪些文件、怎么算过；看 §7 拍三个板。

## 0. 一页看懂（给非技术读者）

**现在到哪了（M0 已完成）**

1. 三套风格 × 三页的样张已经出来了，`data/ppt_out/samples/index.html` 双击就能比；
2. 每条样张都能导出成 **pptx**，里面的字是**能改的文本框**（不是图片），中文不会掉宋体；
3. 数值只剩**一份**（`content/ppt_templates/_builtin/*.json`），文档和代码都读它。

**接下来四件事**

| 里程碑 | 做什么（白话） | 做完你会看到 |
|---|---|---|
| **M1 渲染收口** | 面板里的幻灯片改成"服务端画好、面板只显示"，并用**固定 1280×720 等比缩放**——换面板宽度不再变形 | 面板里的幻灯片和下载出来的一模一样 |
| **M2 质量闸门** | 加一个自动检查：量宽高比、空白、碰撞、失衡 + 溢出/安全线/标题间距，**先记下今天的数值** | 每次改完有数字说话，不再"看着还行" |
| **M3 导出接面板** | 面板「下载」的 PPT 走新链路（同一份 SVG 源），出问题可一键切回老链路；用 **WPS 真机**打开确认 | 点一下下载就得到能改的 pptx，WPS 打开不报修复 |
| **M4 编辑/模板/填充** | 幻灯片页签里能改字、换版式、换主题；能导入学校模板；教案内容自动填进模板 | 老师能自己改稿，不用重来 |

**每一步都能停在"能用"的状态**：M1 之后面板就变好看，M2 之后有数据，M3 之后能下载，M4 之后能编辑。跑不绿验收就不算完成。

## 1. 目标 / 非目标 / 红线

**目标（v1.16.0 交付）**

1. 面板「幻灯片」页签 = 与导出**同一份 SVG 源** + 固定 1280×720 等比缩放；
2. 三套主题可选（面板可切、会话记住），数值全部来自 tokens 单一源；
3. 导出 pptx 走 `svg_to_pptx.py`：原生可编辑文本、中文不掉宋体、**旧路径可一键回退**；
4. 质量闸门跑起来（Edge 无头，不需要装浏览器），**先记基线**再卡验收；
5. 幻灯片页签可编辑（改字 / 条数 / 版式 / 换主题 / 排序）；
6. 「教案中心」的内容能填进模板（`docs/19` §10 填充器）。

**非目标**：不做自由拖拽排版（老师做的是演示稿，不是设计工具）；不引入 HTML deck 运行时（AGPL，见 `docs/22` D11）；不引入需要安装/嵌入的字体；不动教案正文与 Word 导出链路。

**红线（都有测试锁，谁改谁负责）**

| 红线 | 锁在哪 |
|---|---|
| 预览**不落盘**（唯一例外：`data/tmp/ppt_jobs/<job>/` 的受控工作区） | `tests/test_ppt_polish.py` + 新增 `test_slide_deck.py` |
| `content/plans/` **一个字不写**；产物只进 `data/ppt_out/` | 同上 |
| 面板外壳（外层 div / 拖拽 / 收起 / 下载▾）**字节不变** | `tools/uicheck/panel_check.js` |
| skill 关闭 ⇒ 面板清空、但导出仍可用；WPS 关闭 ⇒ 预览不受影响、导出预先拦 | `panel_check.js` + `tests/test_capabilities*.py` |

## 2. 架构决定（在 `docs/22` D1–D12 之上新增）

| # | 决定 | 为什么 |
|---|---|---|
| **D13** | **渲染收在服务端**：面板不再用 JS 拼幻灯片；`POST /api/slide/render` 返回每页 SVG 字符串，面板只做 `transform:scale()` + 翻页/点击 | 布局逻辑只有一份（Python），单测、预览、导出共用 ⇒ 从根上消灭"两套渲染"。这是 M1 的核心 |
| **D14** | **主题随会话**：`GET /api/slide/themes` 列主题；选中项写 `session.meta.doc.ppt_template_id`（`docs/19` §12 已规划）+ localStorage 镜像 | 老师换风格后重新打开还在；服务端读同一字段，导出不会"风格跳变" |
| **D15** | **导出双轨**：新增 `kind="pptx-deck"` → 服务端渲染 SVG → ppt-master 转换；任一硬验收不过 ⇒ **自动回退**现有 `pptx_native` 并在面板说明原因 | 观感改造与导出后端解耦；绝不静默降级 |
| **D16** | **审计不装浏览器**：Edge `--headless=new --dump-dom`（本次已实测：脚本会执行、测量结果能抓出来）⇒ 审计工具用 Python 就够，**不引入 puppeteer / Playwright / npm 依赖** | 少一个依赖就少一处坏点；本机已有 Edge |

## 6.6 R7 · 填充质量返工（按老师 2026-09-27 的验收反馈）

### 6.6.1 根因（都在他自己的 12 页模板上复现过，附证据）

| 老师看到的 | 真正的根因 | 证据（修前） |
|---|---|---|
| **空白页** | 续页只深拷贝了 `has_text_frame` 的形状 → 续页**3 个文本框、0 张图**，底图/装饰全丢 | 10 页教案 → 19 页产物，其中 9 张「（续 N）」页形状数 = 3、图片数 = 0 |
| **模板背景都没有** | 同上（底图是图片，没被拷过去） | 同上 |
| **正文没填进去** | ① 分页拿**模板第一张内容页**（目录页，3 个 20 字的框）的容量去分**所有**页；② 标题按"面积最大"选 → 4 卡片页上整段正文的框（264×160）比真标题框（400×100）还大 → 标题与正文对调，40 字正文被压成 3 个字 | `_paginate` 的 `trim` 记录：cap=5 → 40 字压成「一般地」 |
| **还是乱的** | ① 图形游戏页的「圆/矩形/正方形/三角形」（229×126 这种框）没被认成设计标签，正文被填进图形名里；② 克隆母版是**已经填过**的那张 → 续页带着上一页的文字 | p5「矩形」上压着正文；单测 `test_clone_is_taken_before_writing` |

### 6.6.2 修法（每条都对应一个可复核的判据）

| # | 改动 | 判据 / 为什么这么做 |
|---|---|---|
| **R7-1** | **续页整页克隆**（`slide_fill._clone_slide`）：形状树整棵深拷贝 + `r:embed/r:link/r:id` 重新指向 + 页面 `<p:bg>` 一起抄；图片**复用同一份 image part** | 判据：成品每页的形状数/图片数 = 它自己母版的 → 底图必在；40MB 设计稿不会翻倍 |
| **R7-2** | **按每页自己的槽分页**（`_paginate_pages`）：第 1 页用第 1 页的容量，续页用续页的；一条本页放不下就**换一页放整条**，不砍字数 | 判据：`LOSS_LIMIT=0.6` —— 压缩后不足原文 6 成就换页；模板框本身装不下时记 `too-long`（不再有静默的"压成 3 个字"） |
| **R7-3** | **标题按字号选**（`slide_template._pick_title`）：短文本（≤14 字）+ 字号最大，优先版面顶部；贴页面底边的框（`y+h ≥ 700`）不当标题；有占位符的模板以 `TITLE/CENTER_TITLE` 为准 | 判据：4 卡片页标题 = 「图形的奥秘」；页脚标语「争当图形小侦探！」（字号更大）不算标题 |
| **R7-4** | **设计标签按面积判**（`_is_design_label`）：中文短文本（≤4 字）且（框 ≤200×60**或**面积 ≤ 整页 4%）→ 标签 | 判据：「圆」「矩形」「正方形」「三角形」「小小探险家」都进装饰，一个字不动 |
| **R7-5** | **正文槽下限**（`MIN_BODY_CAPACITY=8`）+ **海报式大字入装饰**（`_is_poster`：字号 ≥40px 且容量 ≤15） | 判据：装不下一句话的小框不再吃正文（「小小探险家」容量 5） |
| **R7-6** | **容量按"允许缩到的最小字号"算**（`_slot_capacity(..., size=)`，0.7 倍 / 不低于 14px），另存 `design_capacity`；写不下就**缩字号**（`_shrink_to_fit`，最多 0.7 倍、不低于 14px） | 判据：`capacity > design_capacity`；40 字正文不被压成 5 字（这是老师最反感的"太过于精简"） |
| **R7-7** | **落位按"最合适的框"**（`_assign_body`）：能装下它的框里挑**面积最大**的（并列取靠上靠左）；空着的正文框清空，设计标签不动 | 判据：卡片页整段正文进 264×160 正文框（不进 264×36 小标题框）；游戏页不再把正文塞进压在图形下的小框 |
| **R7-8** | **克隆在写之前**（`_apply` 先克隆再写；`_fill_slide` 的退路不许抢本页刚写过的框） | 判据：单测 `test_clone_is_taken_before_writing`（修前续页标题被正文覆盖） |
| **R7-9** | **封面/结尾按结构认**（`_looks_like_cover` / `_looks_like_end`）：设计稿模板的版式名是空的，靠"标题框是空的 + 正文槽 ≤1"认封面、靠"谢谢/感谢/再见"认结尾 | 判据：结尾页正确落在模板的「谢谢参与」页；不再报"模板没有封面页" |
| **R7-10** | **校验加两条硬闸**（`_verify_fill`）：「续页设计没丢」（成品每页形状数 ≥ 母版）、「没有空白页」（每页都有文字或图片） | 判据：这两条就是老师这次报的 bug，做成**阻断项**，以后再犯直接红 |
| **R7-11** | **体检脚本自己收拾干净**（`tools/ppt_smoke.py` 收尾删除本次导入的模板） | 判据：跑完体检，老师模板库的选择列表不多出「体检模板/伪造」 |
| **R7-12** | **封面副标题不再被丢**：副标题/元信息并进正文槽（没槽位才只给提示） | 判据：`内容零丢失` 串数 +1（封面副标题也进校验） |
