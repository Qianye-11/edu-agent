## 0. 本版改了什么（相对上一版，逐条）

上一版把"自由摆放、任意字号颜色、插图、导出 PDF"划成 B 类后置、把动画等划成"不做"。
按 ② 的要求，**这一版把"贴近 WPS"当硬目标**重排：

| 上一版 | 这一版（按老师要求改） |
|---|---|
| 字号**只给档位**、颜色**只给语义色** | 档位/语义色仍是**默认**，但**能自定义**（任意字号、取色器、系统字体）；自定义的偏差**只提示不阻断**，右栏留痕、可一键恢复 |
| 拖动 = 只做"偏移微调"，高度不让手改 | **自由摆放**：位置/宽度/高度都能拖能填数值；吸附与参考线**默认开**、可关 |
| 自由文本框 / 图片 → B 类后置 | **提到主线**（R21–R22），并定好"图片存哪、导出怎么带"的规矩 |
| 导出 PDF / 图片 → 先不做 | **做**（R23）：先出 PNG/JPEG，再拼 PDF |
| 动画/切换、母版、表格图表、协作、宏 → 不做 | 仍不做，但**每条写清"替代做法"**（见 §3.3），并说明若要做得付什么代价 |
| 只有"文字槽"能编辑 | **对象模型**：文字块 / 自由文本框 / 图片 / 形状 —— 点谁选谁，选中就有框、手柄、属性 |

### 3.2 插入类（WPS 的"插入"选项卡 —— 本轮**也做**）

| # | 能力 | 规矩（先把边界定死，才不会把系统搞乱） |
|---|---|---|
| B1 | **文本框**（自由位置） | 存在 `slides[i].free[]`（**自由层**）：`{id, kind:'textbox', x,y,w,h, size, font?, color?, align, text, z}`；预览与导出都渲染它 |
| B2 | **图片** | `{id, kind:'image', x,y,w,h, src, z}`；**文件落在 `data/uploads/<会话>/`**（不是 `content/plans`，也不进模板库），导出时嵌入 pptx；预览内联 `data:` |
| B3 | **基本形状** | 矩形 / 圆角矩形 / 椭圆 / 直线 / 箭头（纯矢量，`{kind:'shape', shape:'rect', x,y,w,h, fill, stroke, z}`）|
| B4 | 任意字号 / 字体 / 颜色 | 右栏可填任意字号、选系统字体、用取色器；**偏差只提示不阻断**（右栏显示"偏离设计阶梯"，可一键回到档位） |
| B5 | 表格 | 见 §3.3（暂不做，原因与替代） |
| B6 | 图表 | 见 §3.3 |

### 3.3 不做 / 用别的办法替代（每条都写清代价，便于以后翻案）

| WPS 有 | 我们的处理 | 替代做法 | 真要做得付什么代价 |
|---|---|---|---|
| 动画、切换效果 | ❌ 不做 | 导出 `.pptx` 后**在 WPS 里加动画**（文件本来就是原生可编辑的） | 要往 pptx 里注入动画 XML（python-pptx 不支持），且**原生导出链路（svg→pptx）要保证不丢**；与我们"清动画"的内核需要按文件来源区分 |
| 母版 / 版式编辑 | ❌ 不做 | 我们的 **6 个版式 + 「对齐」标槽位**就是版式能力；老师自己的设计稿可以直接**导入成模板** | 改母版 = 改老师的设计稿（原稿只读是红线）；要做得先改这条红线 |
| 表格 | 🟡 暂不做 | 用"两栏/多块"版式排；或导出后在 WPS 里插 | 要在 SVG 单源里新增表格版式（合并单元格/边框/字号），工作量约等于一个新版式族 |
| 图表 | 🟡 暂不做 | 我们的「图文」版式已有一张矢量示意图；复杂图表导出后在 WPS 里插 | 同上 + 数据模型（数据从哪来） |
| 幻灯片隐藏 | 🟡 后置 | 暂时用"删页/移到末尾" | 小功能，等有需求再加 |
| 演讲实录 / 录制 | ❌ 不做 | 系统自带录屏 | 需要录屏权限 |
| 协作 / 云 / 评论 | ❌ 不做 | 单机本地部署 | 需要服务端多租户 |
| 宏（VBA） | ❌ 不做 | — | 安全与沙箱 |

## 4. 决策（D1–D12，**已按老师 ② 的要求定**；有异议单独说）

| # | 决策 | 为什么 |
|---|---|---|
| **D1** | **两层对象模型**：<br>· **槽位层** = 版式/模板给的文字框（标题、小标签、每个要点…），**内容与位置都可改**；<br>· **自由层** = 老师新加的东西（文本框、图片、形状），本来就自由。 | 这是"既贴近 WPS、又不砸掉既有保证"的关键：**渲染与导出仍然只有一条路**（同一份数据 → 同一份 SVG → 同一个导出器），所以"预览什么样、导出就什么样"照旧成立。 |
| **D2** | **位置/大小全自由**：槽位层的框也能拖走、也能改宽高（数值可填）。**默认开吸附**与参考线（可关）。 | WPS 就是这样；老师要的是"我说了算"。 |
| **D3** | **高度允许手改**（推翻上一版的"只自动"）：默认仍按文字自动长高，**一旦手改就用老师的值**；文字溢出时右栏**如实提示**"这里放不下"。 | 上一版为了"好看"不让改高；老师要贴近 WPS，那就都能改 —— 但**必须提示**，不能让人以为没问题。 |
| **D4** | **字号**：5 档仍是一等公民（下拉里直接选），**另给"自定义"输入**；偏离阶梯时右栏显示"偏离设计阶梯"，一键回档。 | 保住"设计不跑偏"的默认，同时给 WPS 的自由度；偏差**留痕**而不是禁止。 |
| **D5** | **颜色**：语义色（正文/次要/主色/强调）为一等公民，**另给取色器**；用了自定义色，右栏同样留痕。 | 同上。 |
| **D6** | **字体**：主题字体（当前 3 套的中文字体栈）为默认，**另给系统字体下拉**（本机装了哪些列哪些）。 | WPS 有字体框；本机字体清单可由浏览器读（`document.fonts`/系统字体名列表用固定清单兜底）。 |
| **D7** | **右侧立属性栏**（对齐 WPS）：选中对象→该对象属性；未选中→本页属性。底部那条只留页码与视图。 | WPS 的属性就在右侧；也让舞台更宽。 |
| **D8** | **备注写进 `.pptx` 备注页**，预览在编辑区下方。 | 导出后 WPS 里能看到。 |
| **D9** | **放映**用浏览器全屏 + `F5`/`Shift+F5`/`←→`/`Esc`；不做"演讲实录"。 | 官方快捷键清单有据；录制在 §3.3。 |
| **D10** | **操作栈**：拖动/插入/删除/改属性/排序/多选批量都要进撤销栈（本地 30 步，带页号与对象 id）。 | 不贴近 WPS 的撤销会让人不敢动。 |
| **D11** | **导出 PNG/JPEG/PDF 全做**：每页 SVG → 无头浏览器截成 PNG → 逐张嵌进 PDF；JPEG 直接给。 | 老师要"发给学生看"。中文字体走系统字体，**导出前提示字体是否就绪**。 |
| **D12** | **动画、母版、表格、图表、隐藏页 = 暂不做**，替代做法见 §3.3；不影响本轮交付。 | 各有明确代价，做完主线再翻案。 |

## 6. 技术方案

### 6.1 两层数据模型（R14/R15/R21/R22 的地基）

```jsonc
// slides[i] 上新增两个**可选**字段（老数据没有它们 = 现在的样子）
{
  "slots": {                                  // 槽位层：版式给的文字框
    "title":   { "dx": 12, "dy": -8, "dw": 40, "dh": 0, "z": 0 },
    "block:0": { "size": 28, "font": "微软雅黑", "color": "#B45309", "align": "center", "lh": 1.5 }
  },
  "free": [                                   // 自由层：老师新加的对象（按 z 从下到上画）
    { "id": "f1", "kind": "textbox", "x": 120, "y": 480, "w": 420, "h": 70,
      "text": "注意：α 是常数", "size": 24, "color": "#2B2B2B", "align": "start", "z": 1 },
    { "id": "f2", "kind": "image", "x": 900, "y": 120, "w": 300, "h": 200,
      "src": "uploads/abc/1.png", "z": 2 },
    { "id": "f3", "kind": "shape", "shape": "roundrect", "x": 80, "y": 200, "w": 240, "h": 120,
      "fill": "#EEF4FF", "stroke": "#2F6BFF", "z": 0 }
  ],
  "notes": "这里写讲稿"                        // R16
}
```

* `clean_slides`：只认**已知槽位名**与**已知对象类型**；数值夹紧（位置 ±200、宽高 40–1200、字号 8–200、
  行距 0.8–3、颜色只认 `#RRGGBB`）；未知键丢弃；**绝不悄悄改字**。
* `ppt_svg`：槽位层在**发射时**应用覆盖（`Canvas.override(slot)`，`text()`/`paragraph()`/`cv.box()` 共用），
  自由层在正文之后按 `z` 叠加绘制（文本框 → 复用 `paragraph()`；形状 → 现成的 `rect/line/polyline`；
  图片 → `<image>` + 内联 `data:`）。
* **导出走同一个 `render_slide`** ⇒ 预览=导出不需要同步（既有架构红利）。`annotate` 的 `boxes` 也带覆盖后的坐标。
* **审计分两档**：槽位层照旧严查（版式/字号阶梯/边距/碰撞，**error**）；自由层只查**越界与遮挡**
  （**warn**，右栏显示，不阻断 —— 老师自己要摆的，不该被拦住）。

### 6.2 拖动与选中（R14）

* 单击 = 选中（出现选框 + 8 手柄），双击/回车 = 进文字编辑（**改成 WPS 习惯**；现在是一点就编辑）。
* 拖动只改叠加层的 `left/top`，**不重建 SVG**（重建会抢焦点、跳滚动 —— R11 踩过）；松手才提交。
* 提交接口沿用 `POST /api/slide/slot`，扩展成收 `{slot, patch:{dx,dy,dw,dh,size,...}}`；
  自由层对象用 `{object_id, patch}` 走同一接口的另一个分支。
* 吸附候选线：安全边距 / 页面中线 / 同页其它对象边缘 / 页脚线；阈值 6 设计像素。
* 手柄：8 个；`Shift` 拖角 = 等比；角落吸附同参考线。

### 6.3 图片（R22）

* 上传 → `POST /api/slide/upload`（multipart）→ 存 `data/uploads/<会话 id>/<时间戳>-<原名>`，
  返回相对路径；**不写 `content/plans`、不进模板库**（与红线一致）。
* 预览：`<image xlink:href="data:image/png;base64,…">`（沿用 R7 的内联做法，大图先缩到 1600 宽）。
* 导出：python-pptx `add_picture`；原生导出链路（svg→pptx）里把 `<image>` 当作位图元素处理。
* 限制：单张 ≤ 10 MB；支持 png/jpg/jpeg/webp/gif（gif 取第一帧）。

### 6.4 任意字号/字体/颜色怎么不砸掉审计（D4–D6）

* tokens 仍是**默认值来源**（下拉里的档位就是 tokens 的 5 档）；自定义值走 `slots[].size/font/color`。
* `slide_audit` 新增两类**提示**（warn，不阻断）：`font-scale-off`（偏离阶梯）、`font-family-off`（非主题字体）；
  右栏显示"偏离设计阶梯 → 一键回档位"。
* 「一键恢复版式」：单槽 / 单对象 / 整页 / 整册四级。

### 6.5 状态栏、缩放与浏览视图（R13）

* 预览台本来就有 `transform: scale(k)`；状态栏改 `k` 并记忆；「适应窗口」= 现有自动算法；`k>适应值` 时容器 `overflow:auto`。
* 浏览视图：用同一份 `DOCP_SL.pages` 在中栏铺缩略图墙（点一张回普通视图并跳到那一页）。

### 6.6 备注（R16）/ 放映（R17）/ 查找替换（R18）/ 导出 PDF（R23）

* 备注：`export_deck_pptx` 写 `slide.notes_slide.notes_text_frame.text`；python-pptx 读回校验。
* 放映：全屏层铺 `DOCP_SL.pages`；`F5` 从 0、`Shift+F5` 从当前页；页码已由服务端画进 SVG。
* 查找替换：遍历 `slides`（标题/块/两栏/备注/自由文本框）→ 命中列表跳页高亮；替换**走同一条写入路径**（不新开第二种）。
* PDF：每页 SVG → Edge 无头 `--screenshot` 出 PNG（1280×720）→ `img2pdf`/Pillow 拼 PDF（.venv 已有 Pillow）；
  导出前检查中文字体是否可用，缺字体就在结果条里说明（不静默出豆腐块）。
