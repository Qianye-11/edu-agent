# 26 · 幻灯片编辑器（WPS 式）计划书（v1.18.0）

> 老师原话：「**我要像 WPS 那样的 PPT 编辑页面，给我计划数（书）**」。
> 前置：`docs/25` 的 R8–R12 已交付（教案工作台 + 页内点着改字 + 左栏真缩略图 + 删卡片）。
> 本文回答一件事：**离"像 WPS 那样"还差什么、怎么补、哪些不做**。

---

## 0. 一页看懂（给非技术读者）

WPS 演示的界面就五个部分（出处见 §1）：**标题栏 · 菜单栏 · 幻灯片窗格 · 编辑区 · 状态栏与视图工具**。
我们现在已经有了：幻灯片窗格（左栏真缩略图）、编辑区（大舞台 + 点字就改）、菜单栏的一小半。
**缺的是三层"手感"**：

| 缺什么 | 老师的体感 |
|---|---|
| **状态栏** | 右下角没有"第 3 / 12 页 · 100%"和缩放滑块，不能一键"适应窗口" |
| **选中与拖动** | 点文字能改，但**框不能拖**、不能调宽；没有选中框与手柄；没有对齐参考线 |
| **属性区** | 想改字号/颜色/对齐，没地方改（现在只有时长/版式） |
| 备注 · 放映 · 查找 | 每页备注没地方写；不能全屏放映；不能查找替换 |

**有一条硬约束必须先说清楚**：我们的幻灯片是**服务端渲染出来的 SVG**（预览与导出**同一份源**，
`docs/22` D13 锁死），而 WPS 是"自由画布、随便摆"。所以这一版**不追求像 WPS 那样什么都自由**，
而是走**"槽位 + 微调"**：每个文字框有自己的建议位置（模板/版式给的），老师可以**拖着微调**，
偏移量存下来、**渲染与导出都按它来** —— 手感接近 WPS，但"预览=导出""版式体检"两条保证不破。

**不做**（并说明理由）：动画与切换效果（与"清动画"内核正面冲突）、母版编辑、表格/图表/公式、协作与云、宏。

## 3. 差距清单与可行性分类

按"能不能在不破坏既有保证的前提下做"分三类。既有保证 = `docs/22` 的锁定决策：
**SVG 单源（预览=导出）· tokens 单一数值源（5 档字号 / 版式白名单 / 配色占比）· 版式审计闸门 · 导出零改动**。

### 3.1 A 类：照做，不碰契约（先做这些）

| # | 能力 | 说明 | 落点 |
|---|---|---|---|
| A1 | **状态栏**：页码 + 缩放百分比 + 「适应窗口 / 100% / 50–200%」 + `Ctrl+滚轮` | 纯前端；缩放只改预览台的 `transform: scale`，不影响导出 | `static/index.html` |
| A2 | **视图切换**：普通 / 幻灯片浏览（缩略图墙） | 浏览视图 = 把左栏缩略图放大铺满中栏；只读（点一张回普通视图） | 同上 |
| A3 | **选中框 + 拖动**（核心手感） | 点对象→出现选框与 4 个角手柄；拖动改**偏移量**（见 §4 D1），松手落库 | `ppt_svg`（渲染时应用偏移）+ 前端叠加层 |
| A4 | **调宽/调高**（同一套偏移） | 拖右手柄改宽；高度由文字行数决定（自动长高），不让人手改高 | 同上 |
| A5 | **对齐参考线 + 吸附** | 拖动时若与安全边距/页面中线/其他槽边缘对齐（阈值 6px）→ 显示虚线并吸附 | 前端（几何都来自 `boxes`） |
| A6 | **右侧属性栏** | 选中对象时显示：位置（x/y 数值可输入）、宽度、**字号档位**（tokens 的 5 档里选，或"自动"）、**语义色**（正文/次要/主色/强调）、对齐（左中右）、竖直对齐 | `ppt_svg`（同上，偏移+样式覆盖）+ 前端 |
| A7 | **备注** | 编辑区下方一条备注输入；导出写进 `.pptx` 备注页（python-pptx 支持） | `slide_deck.export_deck_pptx` + 前端 |
| A8 | **放映** | `F5` 从头 / `Shift+F5` 从当前页 / `→←` 翻页 / `Esc` 退出 / 右下角页码；全屏用浏览器全屏 API | 前端 |
| A9 | **快捷键补齐** | `Ctrl+S` 保存、`Ctrl+A` 选中本页全部文字块、`Ctrl+E/L/R` 对齐、`Ctrl+±/0` 缩放、`Shift+F9` 参考线与网格 | 前端 |
| A10 | **缩略图拖动排序 + 多选** | `Ctrl+点` 多选缩略图 → 批量删/复制/移动 | 前端 |
| A11 | **查找替换** | `Ctrl+F` / `Ctrl+H` 跨页查文字（块/标题/备注），命中处高亮并可跳页 | 前端（数据在 `slides` 里） |
| A12 | **复制/粘贴块** | 画布内 `Ctrl+C/V`：复制选中的块到本页末尾/下一页 | 前端 |
| A13 | **"恢复版式"** | 每个被拖过的框给一个「恢复」；本页一个「清除本页微调」 | 前端 + 服务端（清 override） |

### 3.2 B 类：能做，但要**扩契约**（做完 A 再评估）

| # | 能力 | 要扩什么 | 风险 |
|---|---|---|---|
| B1 | 插入**文本框**（自由位置） | `slides[i].free[]`（自由层），审计对自由层只查"越界/碰撞"，字号仍限 tokens 档 | 自由层一多，版式体检的"整洁度"指标会失真 |
| B2 | 插入**图片** | 图片要落盘（现在预览不落盘）→ 得定"图片存哪" | 与"预览不落盘"红线冲突，必须单独立规矩 |
| B3 | 任意字号/字体/颜色 | tokens 从"单一数值源"变成"建议值" | 「预览=导出 + 版式不跑偏」这条最核心的保证会松 |
| B4 | 表格 / 图表 | python-pptx 能写，但我们的 SVG 单源渲染要新增版式 | 工作量大，收益不明确 |
| B5 | 导出 PDF / 图片 | 本机没有 LibreOffice；可行路径：Edge 无头把每页 SVG 截成 PNG → 拼 PDF | 中文字体走系统字体，跨机器一致性要验 |

### 3.3 C 类：**不做**（写明理由，避免反复讨论）

| 不做 | 理由 |
|---|---|
| 动画与切换效果 | 与 PPT 优化内核"**清动画**"直接冲突（`docs/19`/`docs/22`）；老师要的是"干净能讲" |
| 母版 / 版式编辑器 | 模板是**老师的设计稿**（原稿只读是红线）；改母版等于改老师的资产 |
| 演讲实录 / 录制 | 需要录屏权限，与"本地、不申请额外权限"的基调不符 |
| 协作 / 云 / 评论 | 单机本地部署，无服务端多租户 |
| 宏（VBA） | 安全与沙箱问题，收益极低 |

## 4. 决策（D1–D9，都有默认值；不同意哪条单独说）

| # | 决策 | 为什么 |
|---|---|---|
| **D1** | **拖动 = "偏移量覆盖"**，不是自由摆放：`slides[i].slots = {"block:0": {"dx": 12, "dy": -8, "dw": 40}}`（边界：`\|dx\|,\|dy\| ≤ 200`、`\|dw\| ≤ 400`）。渲染时按它平移/加宽，**预览与导出走同一个 `ppt_svg`**，所以"预览=导出"仍然成立。 | 我们不是自由画布（`docs/22` D13 锁了 SVG 单源）。偏移覆盖既给到"能拖"的手感，又保住两条保证；而且**能被审计**（拖出边距会被体检报出来）。 |
| **D2** | **高度不让手改**：文字块高度跟着文字行数自动长；只能改宽。 | 手改高 → 文字要么溢出要么留大片空白，正是老师最反感的"容量不足/空得难看"。 |
| **D3** | **字号只给档位**（tokens 那 5 档 + "自动"），**颜色只给语义色**（正文/次要/主色/强调），不给任意取色器与任意字号。 | 保住 tokens 单一数值源与版式审计；任意值会让"预览好看、导出变样"和"配色占比超标"同时发生。 |
| **D4** | **右侧立一栏属性区**（选中对象→显示它的属性；没选中→显示本页属性）。 | 对齐 WPS 的习惯；把现在挤在底部那条里的东西分开，舞台也能更宽。 |
| **D5** | **备注写进 `.pptx` 备注页**（python-pptx 的 notes），预览只在编辑区下方显示。 | WPS 的备注就在编辑区下方，导出后要能在 WPS 里看到。 |
| **D6** | **放映用浏览器全屏 + `F5`/`Shift+F5`/`←→`/`Esc`**，不做"演讲实录"。 | 官方快捷键清单里有 `F5`/`Shift+F5`（有据可依）；录制在 C 类不做。 |
| **D7** | **撤销栈升级为"操作栈"**：拖动、插入、删除、排序、改字号/颜色都要进栈（仍本地 20 步，带页号）。 | 现在只覆盖部分操作；拖动不能撤会让人不敢拖。 |
| **D8** | **B 类一律后置**：先把 A1–A13 做完做稳，再单独评估 B1（自由文本框）/B5（导出 PDF）。 | 一次做太多会同时动渲染、导出与审计三处，回归面太大。 |
| **D9** | **动画/母版/表格图表/协作/宏 = 不做**（§3.3）。 | 与既有锁定决策或产品定位冲突。 |

## 6. 技术方案（几个关键点，都是"能测"的写法）

### 6.1 偏移与样式覆盖（R14/R15 的地基）

```jsonc
// slides[i] 上新增一个**可选**字段（老数据没有它就是原来的样子）
"slots": {
  "block:0": { "dx": 12, "dy": -8, "dw": 40 },              // 位置/宽度微调
  "title":   { "size_role": "title", "color_role": "accent", "align": "center" }   // 语义样式
}
```

* `clean_slides` 收这个字段：只认**已知槽位名**、数值夹紧（`|dx|,|dy| ≤ 200`、`|dw| ≤ 400`）、
  未知键丢弃、`size_role/color_role` 只认登记过的枚举 —— 不认识就丢，**绝不悄悄改字**。
* `ppt_svg`：`cv.box(...)` 与 `text(...)` 都从 `Canvas.override(slot)` 取值，偏移在**发射时**生效；
  `annotate` 的 `boxes` 也带上偏移后的坐标（所以叠加层与 SVG 永远一致）。
* 导出走同一函数 ⇒ **预览=导出**不需要额外同步（这是既有架构的红利）。
* 审计：偏移可能把文字推出边距/造成碰撞 → `slide_audit` 照报，右栏显示"这一处拖出边距了"，
  并给「恢复」。

### 6.2 拖动的手感（A3–A5）

* 叠加层已有绝对定位的 `.dp-box`；拖动时只改它的 `left/top`（以及一个虚线"幽灵框"），
  **不重建 SVG**（重建会抢焦点、跳滚动 —— 这两个坑在 R11 已经踩过）。
* 松手（pointerup）才提交：`POST /api/slide/slot` 扩展成能收 `{slot, patch:{dx,dy,dw}}`；
  本地先乐观生效，服务端回来后采纳清洗结果。
* 吸附：候选线 = 安全边距（`cv.margin`）、页面中线、同页其它槽的边缘、页脚线；
  阈值 6 个设计像素（缩放后视觉约 2–6 屏幕像素）。
* 键盘微调：方向键 1px、`Shift+方向键` 10px（WPS 习惯）。

### 6.3 缩放与状态栏（R13）

* 预览台本来就是 `transform: scale(k)`；状态栏只改 `k` 并记忆（localStorage），
  「适应窗口」= 现在的自动算法，「100%」= `k=1`（舞台会比容器大，给它 `overflow:auto`）。
* 「幻灯片浏览」视图：把左栏缩略图用同一份 `DOCP_SL.pages` 铺到中栏（只读，点一张回普通视图）。

### 6.4 备注（R16）

* 数据：`slides[i].notes`（字符串，≤ 2000 字，`clean_slides` 收）。
* 导出：`export_deck_pptx` 里 `slide.notes_slide.notes_text_frame.text = notes`；
  旧版式（WPS 那条）也一起写。验收：python-pptx 读回、WPS 里肉眼确认。

### 6.5 放映（R17）

* 新开一个覆盖全屏的层（`requestFullscreen()`），把 `DOCP_SL.pages` 一页一张铺开，
  `F5` 从 0、`Shift+F5` 从当前页；`←→`/`空格` 翻页、`Esc` 退出并回到原页。
* 页脚页码已经在 SVG 里（服务端渲染），无需另画。

### 6.6 查找替换（R18）

* 纯前端：遍历 `slides`（标题/块/两栏/备注）找命中 → 列表显示"第 3 页 · 第二块"→ 点一条跳页并高亮；
  替换 = 命中处改文字 + 走 `POST /api/slide/slot`（**不绕过槽位映射**，避免出现第二种写入路径）。
