# 教案中心模板与多页编辑

> 完成日期：2026-09-28  
> 范围：教案中心画布、模板加载、分页保存与 DOCX/HTML 导出

## 1. 本阶段交付

教案中心从“单页 HTML 草稿”升级为“多页教案文档”。页面顶部现在可以选择并套用模板，格式栏可以增加、复制和删除页面，右侧 Agent B 仍可读取整份教案并更新匹配板块。

新增的预置模板：

| 模板 | 适用场景 | 主要结构 |
|---|---|---|
| 完整课时模板（默认） | 常规新授课 | 学情、目标、重难点、过程、板书、作业、反思 |
| 探究式课堂模板 | 问题驱动、合作探究 | 核心问题、情境、自主探究、合作交流、归纳与迁移 |
| 单元复习课模板 | 章节/单元复习 | 知识网络、诊断、典例、易错点、分层训练 |
| 习题讲评课模板 | 作业、测验讲评 | 答题数据、错因分类、典型错题、变式与订正跟踪 |

模板列表仍会包含教师自己导入或保存的模板。

## 2. 页面操作

- **＋ 加页**：在当前页后插入一个空白 A4 页面。
- **复制页**：复制当前页及其全部内容，适合复用表格、页眉或教学过程版式。
- **删除页**：至少保留一页；当前页有内容时会二次确认。
- **页码状态**：显示“第 N / M 页”，点击或把光标移入某页会切换当前页。
- **自动保存**：每次编辑、套模板、加页、复制页或删页后写入浏览器本地草稿。
- **Ctrl/Cmd + S**：立即保存当前多页草稿。

套用模板、新建教案和导入 DOCX 会替换当前全部页面，因此操作前都有确认或明确的文件选择动作。

## 3. 兼容与数据格式

草稿继续使用原键 `localStorage: edu_lesson_word_canvas_v2`，避免老师升级后看不到旧教案。读取时按以下规则迁移：

1. 新草稿识别为 `{version: 4, pages: [...], active, template_id}`；
2. 旧草稿是单段 HTML 时，自动包装为第一页；
3. 迁移后下一次保存自动写成 v4，多页内容不丢失。

后端新增 `GET /api/template/canvas?id=<模板ID>`。它对教案中心统一返回富模板，加载优先级为：

- v2 富模板直接返回；
- v1 模板若保留了 `orig/<id>.docx`，重新读取原稿中的段落、字体与表格样式；
- 没有原稿的 v1 或内置骨架模板只在内存中转成 v2，不改写原模板文件；
- 不存在的模板返回 404，不再静默套用错误模板。

## 4. 导出行为

- **导出 DOCX**：各画布页之间插入 `lesson-page-break`，后端转换为 Word 的真实分页符。
- **下载 HTML**：每一页输出为独立 A4 区块，打印样式按页分页。
- **Agent B**：读取所有页面的正文与表格，优先更新命中的目标单元格；找不到对应板块时，把建议稿追加到当前页。

这里的“页”是显式文档页。某一页内容超过 A4 高度时暂不自动拆页，老师可以使用“加页/复制页”主动编排；这样不会在表格中间产生不可控的自动切割。

## 6. 后续建议

下一阶段可按优先级增加：页面缩略图导航、拖拽调整页序、页眉页脚与页码、当前光标处分割为新页，以及基于实际排版高度的“建议分页”。不建议直接强制自动分页，尤其不要把跨行表格静默截断。
