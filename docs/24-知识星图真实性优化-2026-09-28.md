## 2. 数据约定

`content/kg/graph.json` 是正式图谱数据源：

```json
{
  "id": "even_func",
  "name": "偶函数",
  "chapter": "第三章",
  "section": "3.2",
  "page": 82,
  "wiki_slug": "偶函数"
}
```

其中 `page` 明确表示**教材印刷页码**，调用 `/api/page_image?page=82` 时再由服务统一换算
PDF 物理页，避免 Wiki 物理页与教材印刷页混用。

允许的关系只有：`包含`、`前置知识点`、`可推导`、`相关`。服务启动时校验：

- 节点 ID 唯一且名称、章节非空；
- 所有关系端点存在且不自环；
- 关系类型在白名单内；
- `前置知识点` 构成的有向图无环。

## 3. API

| API | 作用 |
|---|---|
| `GET /api/kg/graph` | 全图、统计与章节节点数 |
| `GET /api/kg/node/{id}` | 节点教材坐标和分类型关系 |
| `GET /api/kg/related/{id}?hops=1` | 一到三跳局部子图 |
| `GET /api/kg/search?q=` | 名称、节号、ID、别名搜索 |
| `GET /api/kg/health` | 图数据结构校验与覆盖统计 |
