# 知识库检索第三阶段优化（2026-09-28）

## 1. 阶段目标

第二阶段已经完成语义切块、混合召回和教学角色标注。本阶段不再缩短知识块，重点解决：

1. 15 题黄金集覆盖过窄，无法发现旁栏、方法题和显式教材坐标问题；
2. 用户直接输入“4.2 节”“第二章复习参考题”时，目标块可能不在 Dense/BM25 候选池；
3. 细粒度块命中准确，但定义条件、推导过程可能延续到相邻块。

## 2. 实现内容

### 2.1 显式坐标确定性召回

检索器继续以 Dense + BM25 + RRF 为主。当问题中存在明确坐标时，额外查询 metadata 并
把结果注入候选池：

- `4.2 节` → `section=4.2`；
- `第二章复习参考题` → `chapter=第二章, heading contains 复习参考题2`；
- `第一章小结` → `chapter=第一章, heading contains 小结`；
- 用户直接复述特定旁栏标题时，按标题补充候选。

该通道只在用户给出明确坐标或标题时启用，并给予确定性加权；普通语义问题仍由原混合
召回决定，不做全局硬排序。

### 2.2 父块相邻上下文补全

`retrieve()` 返回的 Top-K 排名保持不变。进入回答生成前，系统依据
`parent_id / chunk_index / chunk_count` 最多追加两个相邻块：

```text
检索 Top-3（排名证据） → 同父块后邻/前邻（最多 2 块） → 生成与引用校验
```

追加块带 `context_neighbor=true` 和 `neighbor_of=<主命中 ID>`。它们是教材原文，允许正常
引用，但不参与 Recall/MRR 排名计算。当前仅对可可靠定位的教材块启用；用户 PDF 仍保持
原有按页语义块策略。

### 2.3 分类型黄金集 v2

新增 `eval/golden_questions_v2.json` 和 `eval/run_retrieval_v2.py`，共 40 题：

| 类别 | 数量 | 覆盖 |
|---|---:|---|
| concept | 17 | 定义、性质、基本概念 |
| method | 10 | 解题方法、图象、应用 |
| sidebar | 8 | 阅读、信息技术、数学建模等旁栏 |
| coordinate | 5 | 章、节、小结、复习参考题 |

评测要求总体 Recall@3 不低于 0.85，且每个类别不低于 0.70，避免总体高分掩盖某一类完全
失效。运行方式：

```powershell
$env:PYTHONPATH='src'
.venv\Scripts\python.exe eval\run_retrieval_v2.py
```

## 3. 验证结果

| 指标 | 结果 |
|---|---|
| 原 15 题黄金集 | Recall@3 15/15，MRR 0.967 |
| v2 总体 | Recall@3 40/40，MRR 0.942 |
| concept | Recall@3 17/17，MRR 0.971 |
| method | Recall@3 10/10，MRR 0.933 |
| sidebar | Recall@3 8/8，MRR 0.854 |
| coordinate | Recall@3 5/5，MRR 1.000 |
| 全量单元测试 | 349/349 通过，3 项按条件跳过 |
| 知识库健康审计 | `healthy`，0 issue |

首次运行 v2 为 35/40；核对教材后发现其中两题的预期章节标注错误，代码侧则暴露出显式
节号、按章复习题和三角函数应用召回不足。修正评测事实并完成定向优化后达到 40/40。

## 4. 边界与下一步

- 40 题仍不足以代表全部题型，后续应扩展到 100 题以上，并加入人工审核的具体例题与习题。
- 范围外问题不能仅凭固定向量距离判断；下一阶段应建立单独的正负样本校准集，再确定拒答阈值。
- 相邻块补全目前使用固定上限 2；后续可根据问题复杂度和上下文 token 预算动态调整。
- 公式图片继续采用原页图引用，不从损坏文字层推测缺失公式。
