## 1. 怎么用（老师视角）

在对话里**明确要课件**即可，例如：

- 「帮我备一节 3.3 幂函数的课，**要课件**」
- 「**生成课件**」
- 「把这个教案**做成PPT**」

回答下方那条操作行（复制 / 重新生成 / 生成文档）**会多出一个按钮**，并且**自动开跑**：

```
[复制] [重新生成] [生成文档] [课件生成中…（约 20~40 秒）]      ← 自动开始
                              ↓ 约 20 秒
[复制] [重新生成] [生成文档] [下载课件 .pptx]                  ← 点它即下载
```

- 生成内容 = **这条回答本身**（教案 Markdown 或答疑长回答），所以「看到的回答」与「导出的课件」同源；
- 下载文件名带中文（如 `3-3-幂函数_20260926_220530.pptx`）；
- 课件是**原生可编辑**：WPS 里每个形状能单独选中拖动、公式/表格是原生对象（不是整页图）。

### 第一次会多一步「确认」

落盘动作走既有权限表：`export_pptx` 当前策略是 **ask**（他在「权限」里表过态）。
所以第一次点会返回一条确认态，按钮变成 **「确认导出课件」**，点一次即可（以后想省掉这步：
右栏「权限」里把「导出教案为 PPT（.pptx）」改成 **总是允许**）。

## 2. 触发规则：只认显式指令（零打扰是硬要求）

判定在 `courseware.wants_deck(text)`，两类动作词分开处理（`docs/12` 的教训：老师明确讨厌
每条回答都弹卡片 —— 所以这里**不加卡片，只在操作行里多一个按钮，且普通答疑一个不多**）：

| 类别 | 规则 | 例 |
|---|---|---|
| 强动作词 | `生成/做/做个/做一份/整一份/导出/出/来一份/搞一份` + 课件\|ppt\|幻灯片\|演示文稿 | 「生成课件」「把这个教案做成PPT」「导出幻灯片」 |
| 弱动作词 | `要/想要/来个` + 同上，但**后面紧跟疑问语气就不认** | ✅「…的课，要课件」 ❌「要课件吗」 |
| 否定前置 | 动作词前是 `怎么/如何/咋/啥` → 不算 | ❌「怎么做PPT」「如何生成课件」 |

- 强动作词后面跟「吗」**仍算要**（「能生成课件吗？」是请求）；
- 普通答疑（问概念/问一道题）**不会**出现这个按钮 —— `tests/test_courseware.py` 里有负例回归。

## 3. 链路（谁在什么时候做什么）

```
用户输入（含显式课件指令）
   → routing.decide 照旧派单（含「课件/PPT」→ Agent B，教案；要快也可显式 A）
   → 回答流结束：done 事件多带一个 deck:true（web_server 三处 done 都挂：A / S / B）
   → 前端 handleEv('done')：addActions(..., deckOn=true)
        · 追加「导出课件」按钮到既有操作行（不新起卡片）
        · 立刻自动点它一次（"说一句就出"）
   → POST /api/ppt/courseware {markdown: <这条回答>, session_id, title, confirm}
        ① 能力闸门：skill:ppt-master（关掉 → gate=capability）
        ② 权限闸门：动作 export_pptx（ask → gate=permission，前端点确认后 confirm=true 重试）
        ③ courseware.generate()：内容 → 页数据 → ppt_master.generate()（WSL 渲染）
        ④ register_download(pptx) 发一次性令牌 → download_url
   → 前端把按钮变成「下载课件 .pptx」；点它走 /api/wps/download?id=<token>
```

**页数口径**：与「预览 PPT / 导出 PPT · 本地」**同一份解析**（`wps_export.slides_from_markdown`），
所以「预览看到几页，导出的课件就几页」。映射到桥接层的 4 种版式：
封面 + 每个环节一页（Markdown 源 → 要点页 ≤6 条/页；教案中心 DZ 源 → 卡片页 ≤3 张/页；
空环节 → 章节页）。超上限自动分页，续页标题带「（续）」。

## 4. 两种内容源（同一接口）

| 来源 | 传参 | 版式 | 谁在用 |
|---|---|---|---|
| 会话里这条回答 | `markdown` | 封面 + 要点页 | **对话链路（本次）** |
| 教案中心编排台 | `payload`（DZ：`{title, grade, steps:[{name, minutes, points}]}`） | 封面 + 卡片页 | 已支持，前端入口待接（下一步） |

内容来源优先级：`payload` > `markdown` > 会话里最近一份教案（`_last_plan_markdown`）。

## 6. 边界（诚实列出）

1. **历史会话不带这个按钮**：`deck` 标记只随实时 SSE 下发（未写进会话 meta）→ 刷新/切回旧会话后
   按钮不会重建。要的话得在 `_store.append(..., meta=...)` 里补一个字段（三处）。
2. **教案中心还没有入口**：`payload` 那条路后端已通，但编排台工具条上还没加按钮。
3. **生成中不能取消**：按钮置灰等结果（20~40 秒）；后端没有中断机制。
4. **内容不足会明确失败**：页数 <2 时直接返回「内容太少…」，不会白启 WSL。
5. 版式仍只有 4 种（封面/章节/卡片/要点），不含图片/图表/公式排版。
6. 课件的落点是仓库 `data/ppt_courses/`（D 盘、`data/` 不入库）。
