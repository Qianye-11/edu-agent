# 分区可编辑与图层重构 · WPS 对照计划书（2026-09-28）

> 起因：老师看完 `docs/27` 的结构巡检后给了两条要求 ——
> ⑥「ppt 页面内的每个区块要都可以进行调整，并对该页面的每个区块层级进行合适的重构性整理」；
> ⑦「再次与 wps ppt 进行对比。制定计划书」。
> 这一份就是 ⑥⑦ 的答案：先把 WPS 的模型量清楚，再定我们的图层模型与分期。

---

## 一、与 WPS 演示的对照（现状 vs 目标）

| 维度 | WPS 演示 | 我们（R25 之后） | 差距 |
|---|---|---|---|
| 页面单位 | 每页 = 一组**对象**（文本框/形状/图片/表格/图表） | 每页 = **版式槽位**（服务端排好的文字盒）+ **自由层对象**（文本框/形状/图片） | 版式槽位的"身份"是版式给的，不能增删；自由层能任意增删 |
| 选中 | 点任意对象都能选中（含背景形状、图片、占位符） | 版式槽位**都能选中**（每个 `boxes[].slot` 一个可点区域）；自由层对象也能选 | ✔ 已一致（R10/R21） |
| 层级 | 每个对象有 z 序，可"上移/下移一层/置于顶层/底层"，右侧有**选择窗格**列全部对象 | 版式槽位有 `z` 覆盖（±9，`order_z` 重排）；自由层对象按数组顺序叠放 | ✗ 两套层级规则并存、**没有统一的选择窗格**；「回原位」只对槽位有意义 |
| 位置/大小 | 右栏/右键精确数值 + 对齐工具 + 分布 + 组合 | 属性条给绝对数值（槽位是"相对版式的偏移"，自由层是绝对值） | ✗ 两套坐标语义；缺对齐/分布/组合 |
| 文字 | 每个文本框内可富文本（部分加粗/改色） | 整格一套样式（粗/斜/下划线/字号/字体/色/对齐/行距） | ✗ 不支持**段内局部样式** |
| 图层可见性 | 选择窗格能**隐藏/显示**单个对象、重命名 | 槽位可 `hidden`（删除式隐藏，不可恢复显示）；自由层靠数组 | ✗ 没有"隐藏但仍存在"的开关与对象名 |
| 背景/母版 | 母版 + 版式 + 页面三层 | 主题 tokens + 6 版式（服务端渲染） | 大致对等（我们更薄） |
| 导出 | 原生 pptx | 原生可编辑 pptx（同一份 SVG） | ✔ 已一致 |
| 备注 | 备注栏 | 备注栏（R16，写进 pptx） | ✔ 已一致 |

**结论**：我们在"能选中、能改、能导出"这条线上已经对齐 WPS；**没对齐的是"层级与对象管理"**——
WPS 有一张**统一的对象清单 + 单一 z 序 + 显隐/命名**，我们现在是"版式槽位的 z 覆盖"和
"自由层的数组顺序"两套并行，老师看不到"这一页到底有哪些东西、谁压着谁"。

## 二、目标模型：一页 = 一条统一的对象清单

### 2.1 数据（`slides[i].objects[]` 扩成唯一真源，槽位也进来）

```jsonc
// slides[i].objects[] —— 渲染顺序 = 数组顺序（后面的画在上面）
{ "id": "o3", "kind": "text" | "shape" | "image" | "slot",
  // slot 类：只做"接管版式槽位"用，不改版式内容
  "slot": "block:0",            // kind=slot 时必填（对应 slide_deck 的槽位名）
  "name": "要点 1",              // 老师可改名字（选择窗格显示）
  "x": 96, "y": 344, "w": 1096, "h": 37,   // **绝对**设计像素（槽位类由服务端算初始值）
  "hidden": false,              // 隐藏但保留（与"删除"区分）
  "locked": false,              // 锁定位置（防误拖）
  "text": "…", "size": 24, "font": "", "color": "#1A1A1A", "align": "start",
  "bold": false, "italic": false, "underline": false, "lh": 1.3,
  "shape": "rect", "fill": "#EEF2F8", "stroke": "#2F6BFF", "fit": "cover", "src": "uploads/…" }
```

要点：

1. **槽位类对象只是"接管"**：文字仍按版式规则排（换行不截断），它的 `x/y/w/h` 是**初始值**，
   老师一拖就变成偏移量（内部仍写 `slides[i].slots[slot]`，契约不变）；
2. **统一 z**：渲染顺序 = `objects[]` 顺序；`slot` 类的旧 `z` 覆盖**迁移**成数组位置
   （迁移规则：读旧数据时把 `slots[slot].z` 折成排序权重，写回时不再写 `z`）；
3. **`hidden` 与删除分开**：`hidden:true` 保留对象（选择窗格里能重新勾上），删除是移出数组。

### 2.2 面板：右侧加"选择窗格"（照 WPS）

```
选择窗格（这一页 7 个对象）
  👁 要点 1        文本框（版式）   ↑ ↓ ⤒ ⤓ ✕
  👁 图 1 o3      图片            ↑ ↓ ⤒ ⤓ ✕
  👁 形状 o1       矩形            ↑ ↓ ⤒ ⤓ ✕
  🚫 页码          装饰（已隐藏）    ↑ ↓ ⤒ ⤓ ✕
```

* 点一行 = 选中那个对象（与画布同步）；双击改名；
* 👁 切换 `hidden`；↑↓⤒⤓ 调层级（置顶/置底直接挪到头尾）；
* **布局**：与左栏对称（左栏=页，右栏=对象），画布居中；窄屏折叠成抽屉。

### 2.3 画布：所有东西都能点、能拖、能锁

* 槽位/形状/图片/文本框**统一走同一套选中与拖动**（已在 R14/R21 实现，只需把 `slot:` 接进来）；
* 新增：**右键菜单**（对齐/分布/层级/锁定/删除/设为背景）与**对齐工具**（左中右、上中下、等距分布）；
* 锁定（`locked`）时只显示细框，不响应拖动。

## 三、分期（每期都能单独验收）

| 期 | 内容 | 验收 |
|---|---|---|
| **R27** 统一对象清单（数据 + 选择窗格） | `objects[]` 收编槽位（迁移旧 `z`）、右栏选择窗格（选中/改名/显隐/层级）、服务端 `clean_objects` 扩 `kind:"slot"` | 单测：迁移正确（旧 `z` → 顺序）、槽位仍能改字拖动、`hidden` 不进渲染但仍在数据；面板检查：窗格选中/改名/显隐/层级各一次 |
| **R28** 对齐/分布/锁定 + 右键菜单 | 对齐（6 向）、等距分布、锁定位置、右键菜单（与选择窗格同源） | 面板检查：三个对象对齐后 `x/y` 落在同一线；分布间距相等；锁定后拖不动 |
| **R29** 段内局部样式（可选，成本较高） | 文本框内**部分文字**加粗/改色（富文本 run） | 单测：`slides[i].objects[].runs[]` 收口与 SVG `<tspan>` 渲染；导出后 pptx 里 run 级样式正确 |
| **R30** 背景层与母版式对齐（可选） | 明确"背景元素不可选"的规则（现在版式里的装饰不可选），或改成可选+锁定 | 面板检查：装饰可选但默认锁定，不挡其他对象 |

**先做 R27 + R28**：它们是老师点名的"每个区块都能调整 + 层级重构"，且**不引入新的坐标语义**，
是把已有的两套层级合成一套。（原写作 R26–R29，R26 已被"文案与按钮收口"占用，故顺延一期。）

## 四、迁移与风险

| 风险 | 处理 |
|---|---|
| 旧数据里的 `slots[slot].z` | 读时折成顺序权重，一次性迁移；写回只写顺序（保留 `z` 字段兼容旧前端） |
| 槽位的 `x/y/w/h` 语义（偏移 vs 绝对） | 对外统一显示**绝对**值（服务端算 `版式初始值 + 偏移`），写回时反算成偏移 —— 老师看到的与 WPS 一致 |
| 自由层与槽位的 id 空间 | 槽位对象 id 固定 `slot:<槽位名>`，与 `layout:<名字>` 的既有命名一致；自由层仍 `o1/o2…` |
| 选择窗格与缩略图栏的宽度争抢 | 右栏默认折叠成 28px 图标条，点开 220px；画布最小宽度 640px（布局探针会盯着画布占比，不许再掉回 40%） |
| 一次改太多 | 每期独立提交 + 独立验收；`tools/layout_probe.py` 每期复测画布占比 |

### R25（结构）

| 项 | 改法 | 复测 |
|---|---|---|
| ① 下载菜单被卡片裁掉 | 菜单**挂到 body** + `position:fixed` + z=50（绕开 `.row-card` / `.scroll` / `body` 三道裁剪；与 z-index 无关 —— 实测：菜单底边 592 被裁到 223） | `elementFromPoint` 三处取证：盖住卡片 ✓ / 被弹窗(z=80)压住 ✓ / 不压全局导航 ✓ |

| ③ 「属性」卡片位置 | 搬到**当前工具组按钮下面**，成一条（本页行 / 选中行 / 选中后的详细属性整条宽） | 属性条 h≈90px、紧跟 `.dp-toolgroup` ✓ |

### R26（文案与按钮收口）

| 项 | 改法 |
